# Competitor pain points

Researched 5 November 2026 from public comparison pages and review summaries. Most sources are vendor or affiliate comparison pages, and review counts are small in places, so treat these as directional signals, not measured facts.

The research summary is written to `docs/product/competitor-pain-points.md`, with sources. Every app phase must satisfy the "Avenro answer" column.

| Pain point (source) | Avenro answer |
| --- | --- |
| Jira is complex, slow and overkill for small teams; onboarding takes weeks (CostBench, eesel, dev.to comparisons) | Zero-config start: project template (Scrum or Kanban) creates workflow, board and first sprint. Create an issue in ≤ 2 interactions. Server-rendered pages with streaming; interaction budget < 100 ms, LCP < 2 s locally. |
| Linear has limited reporting and customization and does not cover docs or meetings (CostBench, toolfinder) | Built-in sprint report, burndown and velocity on every plan. Meetings, minutes, decisions and documents live in the same project. |
| Meeting tools leave action items needing manual follow-up (Fellow comparisons, Capterra) | One click turns a decision or action item into an issue with a two-way link. Overdue action items appear in the inbox. |
| Seat minimums and per-seat costs climbing (Monday's 3-seat minimum; Asana and ClickUp per-seat complaints) | No minimum. Pay only for active members. Viewers and clients are free. |
| Feature gating behind higher tiers (G2 "missing/limited features" complaints) | One plan with every feature. The trial is the full product. |
| Billing complaints dominate low ratings (Asana Trustpilot) | Price shown with tax before payment, reminders before the first charge and before annual renewal, cancel in the Stripe portal at any time, no hidden fees. |
| Steep learning curve (ClickUp reviews) | First-run checklist, empty states with one clear action, sensible defaults. |
| Lock-in | Full workspace export (JSON and CSV) at any time, including while read-only. |

Sources: [dev.to Linear vs Jira](https://dev.to/pickuma/linear-vs-jira-why-developer-teams-are-switching-in-2026-4c71), [eesel](https://www.eesel.ai/blog/linear-vs-jira), [CostBench Linear vs Jira](https://costbench.com/compare/linear-vs-jira/), [toolfinder](https://toolfinder.com/comparisons/linear-vs-jira), [Capterra Fellow](https://www.capterra.com/p/195920/Fellow/reviews/?page=2), [ClickUp vs Fellow](https://clickup.com/compare/vs/fellow), [CostBench ClickUp vs Monday](https://costbench.com/compare/clickup-vs-monday/), [CostBench Monday vs Asana](https://costbench.com/compare/monday-vs-asana/), [prospeo Monday pricing](https://prospeo.io/s/mondaycom-pricing-reviews-pros-and-cons), [Stripe free trials](https://docs.stripe.com/payments/checkout/free-trials), [Stripe Radar free trial abuse](https://docs.stripe.com/radar/free-trial-abuse). Most of these are vendor or affiliate comparison pages; the summary file says so.
